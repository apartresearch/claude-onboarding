# Claude onboarding

Gets a team's non-developers using Claude Code in the Claude desktop app on their own email, calendar, Drive, Slack and Notion: what to install, what to connect, and prompts worth trying on day one. Each person signs in with their work account and connects their own tools, so Claude sees exactly what they can already see.

| File | For | What |
|------|-----|------|
| [guide.md](guide.md) | everyone | Set-up, step by step, including Notion for guest accounts and when to use what |
| [SETUP-FOR-CLAUDE.md](SETUP-FOR-CLAUDE.md) | your Claude | Instructions Claude follows to set you up: what it does itself, what it asks you to click |
| [prompts.md](prompts.md) | everyone | Starter prompts to adapt, each with the connectors it uses |
| [admin.md](admin.md) | the Claude Team Owner | Seats, connectors and settings to switch on first, and a test run before a newcomer starts |

## The fast way

1. Install the Claude desktop app from https://claude.com/download, sign in with your work account, and open the **Code** tab in a folder of your choice (guide steps 1 and 2).
2. Send Claude this repository's address with: "Read SETUP-FOR-CLAUDE.md in this repository and set me up."

Claude does what it can itself and tells you exactly what to click for the rest. Steps marked *(unverified)* haven't been walked end to end yet.
